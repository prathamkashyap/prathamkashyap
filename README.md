## Selected projects

### [<img src="assets/profile/projects/ai-systems.svg" width="23" align="middle" alt="" /> AI Systems Lab](https://github.com/prathamkashyap/ai-systems-lab)

An LLM inference gateway that coalesces duplicate requests, streams responses, and routes around failing providers. A local playground and mock provider make the gateway and hybrid retrieval testable offline. [Architecture](https://github.com/prathamkashyap/ai-systems-lab/blob/main/system-design/architecture.md)

<sub>Python · FastAPI</sub>

### [<img src="assets/profile/projects/libris.svg" width="23" align="middle" alt="" /> Libris](https://github.com/prathamkashyap/libris)

A library management app for cataloguing, loans, returns, and member access. Transactional locking protects concurrent circulation updates, and Flyway tracks database migrations. [Product tour](https://github.com/prathamkashyap/libris#product-tour)

<sub>Java · Spring Boot · MySQL</sub>

### [<img src="assets/profile/projects/athenaeum.svg" width="23" align="middle" alt="" /> AthenaeumAI](https://github.com/prathamkashyap/AthenaeumAI)

An adaptive learning app that generates quizzes from uploaded study material. It calculates mastery and review schedules from recorded answers. [Learning app](https://athenaeumai.tech)

<sub>React · Node.js · MongoDB · Redis</sub>

### [<img src="assets/profile/projects/fact-knowledge.svg" width="23" align="middle" alt="" /> Fact Knowledge Layer](https://github.com/prathamkashyap/fact-knowledge-layer)

An offline pipeline that extracts facts from PDFs and links each claim to its page and source sentence. It compares claims across documents and checks whether differences in scope or reporting period explain apparent conflicts.

<sub>Python · FastAPI · SQLite</sub>

### [<img src="assets/profile/projects/dataset-intelligence.svg" width="23" align="middle" alt="" /> Evidence-Driven Dataset Intelligence](https://github.com/prathamkashyap/evidence-driven-dataset-intelligence)

A local-first dataset recommender that checks metadata against evidence, filters out incompatible candidates, and avoids recommending mirrors of the same dataset. [Research companion](https://evidence-driven-research-companion.vercel.app/) · [Paper](https://github.com/prathamkashyap/evidence-driven-dataset-intelligence/blob/main/paper/final_submission/main.pdf)

<sub>Python · Research prototype</sub>
